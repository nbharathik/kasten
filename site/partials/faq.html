Questions

Good to know

Is Kasten free?

Yes. Kasten is free and open source, under the MIT license.

Where are my notes kept?

In a folder you choose, as Markdown, YAML and JSON Canvas files. Kasten keeps nothing about your notes anywhere else. Only API keys live outside it, in your system's keychain.

Does it work offline?

Yes. Writing, linking, whiteboards, search and history all work without a connection. Only AI, backups to GitHub or another git host, Get latest and the update check need the network. A backup file to a folder works offline too.

Can I use it alongside Obsidian?

Yes. Kasten opens an Obsidian vault as it is, with its folders kept as folders, or imports it into Kasten's own layout as one change you can undo. Links, embeds and tags work in both.

Which AI can I use?

Anthropic's API, any OpenAI-compatible server, or a model running on your own computer. AI agents such as Claude Code connect over MCP. All of it is optional.

How do I back up my notes?

In Settings → History and backup. Sign in with GitHub and Kasten makes a private repository and pushes to it a few minutes after changes, never with force. Or paste a token for any other git host, or choose a folder that Dropbox, Google Drive or OneDrive keeps in sync: Kasten writes a checked backup file there each day and keeps the newest seven. Backup files aren't encrypted, so keep them somewhere private.

Does it sync between computers?

Kasten is desktop-first: backup keeps your notes safe and moves them to a new computer, but it isn't live sync. On a second computer, restore from your backup, then use Get latest when you switch. It never overwrites: if both computers changed a page, the other version is kept beside yours as a copy.

What happens to what I write in the demo?

The demo runs entirely in your browser, on sample notes. What you write stays in this browser only.
