Yours

Private by design

No account, no cloud of ours and no lock-in. Kasten is a program on your computer that works on a folder of files.

No account

Nothing to sign up for. Kasten opens a folder and you start writing.

Your folder, your files

Markdown, YAML and JSON Canvas that any editor can open. Back them up to GitHub, any git host, or Dropbox, Drive or OneDrive.

History you own

Saved changes are recorded, with typing batched, in the vault's own .git folder, pushed only to a backup you confirmed.

Keys in your keychain

API keys live in the system keychain, each tied to the address it was saved for.

Choose trusted vaults

Kasten applies path and credential checks. Open vaults from trusted sources and keep an independent backup.

Open source

MIT licensed. Read every line, build it yourself, or help make it better.
