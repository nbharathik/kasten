Kits and backup

Start ready, stay safe

Begin from a kit that already knows how you like to work, then keep a copy of everything somewhere you trust. Kasten is desktop-first: backup keeps your notes safe and moves them to a new computer. It isn't live sync.

Starter kits

Daily planner, Second brain, Zettelkasten, Getting Things Done, Student or Research: home pages, tags, templates and boards, added as one change you can undo.

58 templates

Meetings, reviews, book notes, trips and more, with the day, week and time filled in. Save any page as a template of your own.

Back up to GitHub

Sign in once and Kasten makes a private repository and pushes to it a few minutes after you write, never with force. Or paste a token for any git host.

Or to any folder

Point it at Dropbox, Google Drive, OneDrive or a disk. Each day a backup file is written there and checked, and the newest seven are kept.

Restore anywhere

On a new computer, restore from GitHub, a git address or a backup file, with every page and every change in history.

Get latest, by hand

Moving between two computers? Get latest brings the other one's changes in and never overwrites: if both changed a page, theirs is kept beside yours.
